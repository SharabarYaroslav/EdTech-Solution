01Запатентована технологія Vector Networks

Інструмент Pen Tool (P) у Figma побудований на революційній математичній моделі Vector Networks (Векторні мережі), яка усуває вікове обмеження класичних графічних редакторів (Adobe Illustrator, Photoshop). У традиційних програмах векторний шлях є суворо лінійним ланцюгом, де кожна вершина може мати лише два з'єднання: вхід та вихід.

У Vector Networks з одного вузла (вершини) може виходити будь-яка кількість сегментів у довільних напрямках. Це дозволяє проектувати складні іконки, ізометричні куби, блок-схеми та символи всередині єдиного векторного об'єкта — без штучного дублювання точок і багатошарового накладання шляхів.

02Інструментарій режиму Vector Edit Mode

Подвійний клік або натискання клавіші Enter на обраному векторному шарі чи геометричному примітиві активує спеціалізований режим Vector Edit Mode. У цьому середовищі верхня панель інструментів трансформується, відкриваючи доступ до високоточних операцій над геометрією:

  • Bend Tool — дозволяє миттєво вигинати прямі сегменти в криві Безьє простим перетягуванням самої лінії.
  • Variable Width Tool — забезпечує локальну зміну товщини обводки у будь-якій точці контуру для каліграфічної та ілюстративної графіки.
  • Shape Builder — дозволяє інтерактивно об'єднувати (Merge), вилучати (Extract) або віднімати (Subtract) пересічні векторні області простим протягуванням курсора.

Lasso Tool Q Довільне виділення групи точок для їх спільного переміщення чи масштабування через Bounding Box.

03Математика безперервної кривизни та Squircles

Для побудови естетично довершених інтерфейсів Figma використовує алгоритм Corner Smoothing (Згладжування кутів). Звичайне геометричне скруглення (Corner Radius при 0% згладжування) має різкий візуальний перехід у точці, де пряма лінія сторони переходить у дугу кола — людське око фіксує цей перепад кривизни як мікроскопічний «злам».

Параметр Corner Smoothing трансформує кути у математичні супереліпси (Squircles), де радіус кривизни плавно наростає від нуля до максимуму. Значення 60% (пресет iOS) точно відтворює фірмову геометрію іконок та апаратних корпусів екосистеми Apple.

Аналіз кривизни контуру:

При 60% згладжуванні дуга починається раніше вздовж прямої грані (червоний пунктир показує звичайний радіус 0%), усуваючи оптичний злам на переході.

🔴 Пунктир: 0% (коло) 🟣 Фігура: Squircle
✨ Естетика преміального UI

Встановлення Corner Smoothing на рівні 60% для прямокутників, карток і кнопок миттєво надає інтерфейсу візуальної м'якості та преміальності, усуваючи грубість стандартних геометричних кіл на стиках ліній.
