01Шрифтовий рушій та підключення гарнітур

Типографічна підсистема Figma інтегрована з повною бібліотекою хмарних гарнітур Google Fonts. Для використання локальних корпоративних чи комерційних шрифтів, встановлених в операційній системі, застосовується десктопна версія Figma або спеціальний системний сервіс Figma Font Helper при роботі через браузер.

Текстовий шар у Figma функціонує як векторний контур, збагачений атрибутивними типографічними метаданими. Платформа забезпечує безшовну роботу як зі статичними гарнітурами (фіксовані накреслення Regular, Medium, SemiBold, Bold), так і з сучасними варіативними шрифтами (Variable Fonts).

02Варіативні шрифти та точні метрики тексту

Variable Fonts надають безперервний контроль над параметрами уздовж осей варіативності: щільності (Weight від 100 до 900), оптичного кеглю (Optical Size) та кута нахилу (Slant). Це дозволяє налаштовувати оптичну вагу шрифту з точністю до одиниці, оптимізуючи читабельність на мобільних дисплеях.

Line Height (інтерліньяж) контролює відстань між базовими лініями рядків і задається у відсотках (%), пікселях (px) або значенні Auto, яке вираховується автоматично на основі шрифтової таблиці гарнітури. Letter Spacing (трекінг) керує міжосьовим інтервалом символів і може задаватися як у пікселях, так і у відсотках від поточного розміру кеглю.

⚠️ Правило надійної верстки

Ніколи не застосовуйте Fixed Size для динамічних текстових блоків у реальних продуктах. При зміні мови (наприклад, з англійської на німецьку чи українську) довжина слів зростає на 20–35%, і фіксований контейнер призведе до фатального обрізання контенту.

03Поведінка текстових контейнерів та інтеграція змінних

Геометрична поведінка текстового шару визначається трьома режимами ресайзингу рамок: Auto Width, Auto Height та Fixed Size. Правильний вибір режиму є критичним при інтеграції тексту в Auto Layout контейнери.

Усі числові та строкові параметри типографіки (кегль, інтерліньяж, сімейство шрифту) можна зв'язувати з дизайн-токенами через Figma Variables (String та Number). Це дозволяє автоматично адаптувати типографічну ієрархію під час зміни розміру екрана або перемикання мовної локалізації.

Режим / ПараметрОдиниці вимірюванняМеханіка поведінки та сфера застосування
Auto Width Динамічна ширина Рамка автоматично розтягується по горизонталі під довжину тексту. Використовується для кнопок, чипсів, навігаційних меню.
Auto Height Фіксована W / Динамічна H Ширина контейнера задається жорстко, висота нарощується автоматично по мірі додавання рядків. Ідеально для абзаців, карток і статей.
Fixed Size Фіксовані габарити px Ширина та висота строго обмежені. Текст, що не вміщується, обрізається або виходить за рамки. Застосовується вкрай рідко.
Line Height %, px або Auto Визначає висоту рядка. У вебі стандарт для основного тексту складає 140–160%, для великих заголовків — 110–125%.
Letter Spacing % або px Трекінг символів. Для великих заголовків рекомендується злегка від'ємний трекінг (-1%..-2%), для капслоку — розрядка (+5%..+10%).
