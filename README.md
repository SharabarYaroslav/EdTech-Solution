# EdTech Solutions — вебресурс магістерського дослідження

**Тема:** «Використання цифрових технологій для розвитку дизайн-мислення майбутніх учителів інформатики»
(УДУ імені Михайла Драгоманова)

## Запуск
Відкрити `index.html` у браузері (сервер не потрібен).

## Структура сайту
**Шапка:** логотип + назва · Курс ▾ (мега-меню з 5 секціями) · Практика ▾ · Відеокурси · Вхід/Зареєструватися + аватар
**Основна частина:** про сайт та навігація
**Низ сайту:** пошта, телефон, розробник, посилання

```
Project/
├── index.html     — Головна (про сайт, секції курсу, навігація, практика, відео, FAQ)
├── course.html    — Курс: огляд секцій; course.html?s=<id> — сторінка секції з темами
├── practice.html  — Практика: тести, Figma, гарячі клавіші, розробка матеріалів
├── video.html     — Відеокурси
├── auth.html      — Вхід / Реєстрація + завантаження аватара (демо, без сервера)
├── css/style.css  — усі стилі
└── js/main.js     — структура меню (COURSE, PRACTICE, CONTACTS), шапка, футер, інтерактив
```

### Секції курсу (id для посилань)
1. `design` — Дизайн
2. `figma` — Занурення у Figma
3. `ui` — UI елементи
4. `materials` — Розробка навчальних матеріалів
5. `sites` — Лендинги та багатосторінкові сайти

## Як змінити меню / контакти
Відредагуйте масиви `COURSE`, `PRACTICE` та об'єкт `CONTACTS` на початку `js/main.js` —
зміни автоматично з'являться в шапці, футері, на головній та на сторінці курсу.
