01Системна роль Layout Guides та їх типологія

Модульні сітки у Figma, які отримали оновлену назву Layout Guides (історично відомі як Layout Grid), є фундаментом структурної гармонії, візуального ритму та передбачуваної адаптивної верстки. Сітки застосовуються виключно до фреймів та компонентів і виступають невидимим каркасом, до якого магнітяться об'єкти під час проектування.

Архітектура Figma дозволяє накладати необмежену кількість сіток на один фрейм одночасно, комбінуючи три базові типи:

#️⃣

Uniform Grid

Квадратна сітка →
Рівномірна піксельна сіткаВикористовується переважно для високоточного конструювання іконок (Pixel Grid з кроком 8px або 10px) та модульних ілюстрацій.
🏛️

Columns

Вертикальні колонки →
Колонкова сіткаГоловний інструмент адаптивної веб- та мобільної верстки: 12 колонок на десктопі (ділиться на 2, 3, 4, 6), 8 на планшеті та 4 на смартфоні.

02Механіка колонкових та рядкових сіток

Для побудови екранних інтерфейсів ключовими є Columns та Rows. Сітка налаштовується у двох основних режимах поведінки: Stretch (Адаптивний), коли колонки автоматично розтягуються і стискаються разом із шириною фрейму, та Fixed (Фіксований: Left, Right, Center), коли колонки зберігають жорстко задану ширину у пікселях.

Параметр сіткиМатематична та структурна логіка в інтерфейсі
Count (Кількість) Кількість направляючих. Стандарт: Десктоп — 12 колонок, Планшет — 8, Мобільні — 4.
Type: Stretch Динамічна ширина колонки за формулою: W = (ШиринаФрейму − 2×Margin − (Count−1)×Gutter) / Count.
Type: Fixed Фіксація по позиції (Left / Right / Center) з жорстким параметром Width. Залишок іде під динамічні поля.
Margin (Поля) Зовнішні відступи безпеки від країв фрейму до першої та останньої колонок (16–24px mobile, 64–120px web).
Gutter (Міжколонка) Фіксований простір між сусідніми колонками або рядками (зазвичай становить 16, 20 або 24px).

04Інженерний стандарт 8-Point Grid System

Сучасна індустрія цифрового дизайну базується на математичній системі 8-Point Grid. Її суть полягає у тому, що всі габарити об'єктів, висоти рядків, поля та відстані між елементами повинні бути кратними числу 8 (8, 16, 24, 32, 40, 48, 56, 64px і т.д.). Для дрібних компонентів (іконок, бейджів, підписів) допускається використання проміжного кроку у 4px.

Існують два підходи до реалізації цієї системи у верстці:

  • Hard Grid (Жорстка сітка) — усі об'єкти фізично прив'язуються координатами до фонової сітки з кроком 8px.
  • Soft Grid (М'яка сітка) — визначає лише відносні відступи (Padding та Gap в Auto Layout) кратними 8px між самими елементами. Саме Soft Grid є домінуючим підходом у гнучкій адаптивній веброзробці.
🔬 Чому саме 8 пікселів?

Більшість сучасних дисплеїв мають стандартну роздільну здатність, яка ділиться на 8 без залишку, а операційні системи використовують коефіцієнти масштабування щільності пікселів (@1x, @2x, @3x або 1.25x, 1.5x). Число 8 ідеально ділиться на 2 і на 4, що гарантує відсутність розмитих «напівпікселів» при рендерингу графіки на Retina та OLED екранах.
