01Механіка динамічної розкладки та просторові потоки

Інструмент Auto Layout перетворює статичні фрейми на динамічні розумні контейнери, які автоматично розраховують просторове положення дочірніх елементів за аналогією з CSS Flexbox. Об'єкти самостійно зміщуються та підлаштовують свої межі при додаванні, видаленні або редагуванні текстового наповнення.

Напрямок потоку (Direction) визначає вектор розміщення елементів: горизонтальний (Horizontal — вісь X), вертикальний (Vertical — вісь Y) або потік з переносом рядків (Wrap). Режим Wrap автоматично переносить дочірній елемент на новий рядок або колонку, коли для нього закінчується доступний лінійний простір контейнера.

02Відступи, інтервали та правила ресайзингу

Padding визначає внутрішні поля між зовнішнім контуром фрейму та його дітьми. Figma дозволяє задавати як симетричні, так і незалежні поля для кожної з чотирьох сторін (Top, Right, Bottom, Left). Параметр Gap контролює фіксовану відстань між сусідніми об'єктами або перемикається у значення Auto (Between, Around, Evenly) для рівномірного розподілу елементів уздовж осі контейнера.

Кожна з двох осей (W та H) окремо контролюється режимами ресайзингу: Fixed, Hug Content та Fill Container.

Режим ресайзингуПоведінка по осі W або HТиповий UI приклад
Fixed (Фіксований) Габарити суворо зафіксовані у пікселях, не реагують на дітей. Аватари (40×40px), іконки, картки із жорстко заданою геометрією.
Hug Content (Обтискання) Контейнер стискається до мінімально можливих меж контенту + падінги. Кнопки з динамічним текстом, теги, чипси фільтрів, тултіпи.
Fill Container (Заповнення) Шар розтягується на весь доступний простір батьківського фрейму. Текстові блоки в адаптивних картках, розділювальні лінії, інпути форми.

04Ignore Auto Layout (Absolute Positioning) та вкладеність

Функціонал Ignore Auto Layout дозволяє виключити конкретний шар із загального потоку розкладки, зберігаючи його всередині батьківського фрейму. Такий об'єкт позиціонується у довільній точці за правилами Constraints (наприклад, червоний бейдж лічильника сповіщень у верхньому кутку іконки або кнопка закриття у кутку модального вікна).

Побудова складних інтерфейсів реалізується через гніздування (Nesting) фреймів: вертикальний Auto Layout контейнер об'єднує горизонтальні рядки, кожен з яких адаптується за власними правилами.

🏆 Золоте правило Flexbox у Figma

Для побудови бездоганної адаптивної картки: зовнішній фрейм повинен мати ширину Fill Container або Fixed, а висоту — Hug Content. Внутрішній текстовий шар обов'язково має бути Fill Container по ширині та Auto Height по вертикалі.
