01Формати експорту та критерії вибору

Figma надає інженерний інструментарій експорту графічних активів через панель Export у правому сайдбарі (або масовий експорт через Shift + Cmd/Ctrl + E). Правильний вибір формату гарантує максимальну чіткість відображення та мінімальну вагу кінцевого цифрового продукту:

  • PNG використовується для растрової графіки з прозорим альфа-каналом (3D-ілюстрації, елементи з м'якими тінями, скріншоти інтерфейсу).
  • JPG застосовується для фотографічних зображень без прозорості з високим коефіцієнтом компресії.
  • SVG є світовим стандартом для векторних іконок, логотипів та інтерфейсних елементів вебу.
  • PDF використовується для векторних презентацій, дизайн-специфікацій та поліграфії.

02Системне масштабування та щільність пікселів

Для растрових форматів (PNG, JPG) доступне експортування у різних масштабах щільності пікселів: 0.5x, 1x, 2x, 3x, 4x. Системні суфікси масштабування (наприклад, @2x або @3x) автоматично додаються до назв збережених файлів, що необхідно для екранів Apple Retina та сучасних мобільних пристроїв високої щільності.

Також підтримується точне масштабування за габаритами за допомогою суфіксів фіксованої ширини (наприклад, 512w) або висоти (1024h).

ФорматПідтримувані параметриРекомендована сфера застосування
PNG Масштаби 0.5x – 4x, альфа-канал прозорості. Растрові ілюстрації, напівпрозорі графічні активи, скріншоти інтерфейсу.
JPG Масштаби 0.5x – 4x, налаштування стиснення. Фотографії, важкі фонові зображення, де прозорість не вимагається.
SVG Outline Text, Include ID, Simplify Stroke. Векторні іконки, логотипи, масштабована векторна графіка для фронтенд-верстки.
PDF Векторний багатосторінковий експорт документа. Презентаційні слайди, дизайн-специфікації, друковані брошури та макети.

03Специфікації експорту векторного SVG

При експорті в SVG інспектор Figma надає три спеціалізовані опції оптимізації вихідного XML-коду:

  • Outline Text — конвертує текстові шари у замкнені векторні криві, гарантуючи ідентичне відображення логотипа навіть за відсутності фірмового шрифту у системі користувача.
  • Include "id" Attribute — додає імена шарів як атрибути id="..." до SVG-тегів для прямої анімації чи маніпуляцій через CSS та JavaScript.
  • Simplify Stroke — математично спрощує векторні точки обводок для зменшення розміру файлу.
💻 Порада для фронтенд-оптимізації: fill="currentColor"

При експорті іконок у SVG обов'язково перевіряйте, щоб у них не було зафіксованих жорстких кольорів заливки, якщо розробники планують фарбувати їх динамічно (наприклад, при ховері або перемиканні теми) через CSS-властивість fill="currentColor".
